# AniTala Landing Page Images

Drop your images here! The system automatically detects and loads them in the landing page slots.

## Supported Filenames & Formats

You can use either `.jpg`, `.png`, or `.webp` formats:

| Slot | File Name (Any of these) | Where it appears |
| :--- | :--- | :--- |
| **Hero Card** | `hero.jpg` / `hero.png` / `hero.webp` | Top-right of hero section (Rice terrace / lush field) |
| **Why AniTala** | `why.jpg` / `why.png` / `why.webp` | Left card in "Why AniTala" section (Philippine farm photo) |
| **Step 1** | `step1.jpg` / `step1.png` / `step1.webp` | "01 · Pin Your Field" card (Field map illustration/photo) |
| **Step 2** | `step2.jpg` / `step2.png` / `step2.webp` | "02 · Soil & Priorities" card (Soil testing/texture photo) |
| **Step 3** | `step3.jpg` / `step3.png` / `step3.webp` | "03 · Seasonal Rotation" card (Diverse crop harvest photo) |

*Note: If an image is not present or fails to load, AniTala gracefully falls back to the high-contrast design gradients with subtle topographic contours.*
